# Contributing

First of all, thank you for your interest in contributing to 3D Cursor Transform!

Whether you're reporting a bug, suggesting a new feature, improving the documentation, testing the add-on, or contributing code, your help is greatly appreciated.

## Reporting Bugs

Before creating a bug report, please check whether the issue has already been reported.

When reporting a bug, please include as much information as possible, such as:

- The version of 3D Cursor Transform.
- The Blender version you are using.
- Your operating system.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- Screenshots or screen recordings, if applicable.

## Suggesting Features

Feature suggestions are always welcome.

When proposing a new feature, please describe:

- The problem you're trying to solve.
- Your proposed solution.
- Any alternative solutions you've considered.

Please keep in mind that not every feature request can be implemented, but every suggestion is appreciated.

## Pull Requests

Before opening a pull request, please ensure that:

- Your changes are focused on a single improvement or fix.
- Existing functionality continues to work as expected.
- New functionality has been tested.
- Documentation is updated where necessary.

If possible, please test your changes in multiple supported Blender versions.

Please write clear commit messages and provide a concise description of your changes.

## Code Style

Contributions should follow Blender's Python coding conventions and the general recommendations of PEP 8.

Please also follow the existing structure, naming conventions, and formatting used throughout the codebase.

Code should remain clear, readable, and appropriately documented. New classes, operators, handlers, keymaps, and runtime properties must be registered and unregistered correctly.

## Project Maintenance

3D Cursor Transform is currently maintained by a single developer.

Contributions are always welcome. If the project continues to grow, I would be happy to collaborate with additional maintainers.

If you have been making high-quality contributions over time and are interested in helping maintain the project, or eventually taking over its maintenance, feel free to get in touch.

The long-term goal of this project is to remain useful to the Blender community, regardless of who maintains it in the future.

## Questions

If you're unsure about a proposed change, feel free to open an issue or start a discussion before beginning work.

## Thank You

Every contribution, no matter how small, helps improve 3D Cursor Transform.

Thank you for taking the time to contribute!
